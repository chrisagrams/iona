The 200m denoise fine-tune under DeepSpeed ZeRO-2, and the template for the 200m grid. Identical to the 50m DeepSpeed config except for the checkpoint, so any difference between the two size ladders is attributable to encoder capacity alone. The 50m grid's 216 arms decided which axes this grid still needs to sweep. GRID ARM: lr=2e-4, encoder at 1.0x the head's rate, effective batch 48 giving about 7,266 optimizer updates, 4 epochs, head width 512. Epochs and head width are fixed rather than swept because the 50m grid measured their spread at 0.012 and 0.007 AUROC respectively, against 0.111 for encoder_lr_scale and 0.109 for the learning rate. lr 5e-4 extends past the 50m range, where 2e-4 was both the best value and the boundary, so the optimum was never bracketed.
