The control for the entire denoise programme: the 50m ARCHITECTURE with randomly initialised weights, trained identically to the pretrained runs. random_init builds the model with from_config, so the checkpoint's tensors are never read at all. It answers the question the 216-arm grid raised but could not settle. Frozen-encoder arms averaged 0.760 against 0.872 unfrozen, which says the value comes from ADAPTING the encoder rather than from its features as they stand -- but adapting what? If a random encoder trained the same way reaches a similar AUROC, then pretraining contributed architecture and nothing else, and every checkpoint on flare is worth revisiting. If it falls well short, the pretraining is doing real work that the frozen probe simply could not expose. ABLATION ARM: lr=5e-4, 4 epochs, effective batch 12, encoder at full rate and head width 512. The pretrained 50m grid's best arm reached 0.9320 test AUROC and its frozen-encoder arms averaged 0.760; where this lands between those two numbers is what pretraining is worth.
