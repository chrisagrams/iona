PAIR-LOSS ARM: independent per-pair terms instead of in-batch softmax. 8 pairs per minibatch (16 spectra) with gradient_accumulation_steps 8, so an optimizer step sees 64 pairs at the memory of 16 spectra -- the point of the formulation, since pair terms decompose and softmax terms do not. positive_fraction 0.5 sets the in-group/out-group balance directly, which PK sampling could only change by changing the batch shape. pair_margin 1.0: different peptides are pushed to at least this distance and then ignored; embeddings are unit-norm so d lies in [0,2] and d^2 = 2-2cos, making 1.0 ask for cosine <= 0.5. lr 1e-4, chosen from the settings that never collapsed in the softmax grid. Read against a softmax reference of 5.75 +/- 0.75 and a random floor of 1.35; with one run per arm only a gap above ~2 is meaningful, so this is a viability screen and the best arms need repeats afterwards.
