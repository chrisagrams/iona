SEED-VARIANCE ARM, seed 2 of 0, 1, 2, 3, 4, 5: the best contrastive configuration (lr 5e-4, KL 10, temperature 0.07) with the TRAINING seed varied and the train/validation split held fixed at split_seed 0, so every arm is scored on identical held-out data. Read against configs/sweep-repeat, which runs the same configuration six times at a FIXED seed: that grid measures nondeterminism alone, this one measures the seed effect on top of it, and the difference in spread is the seed's own contribution. Motivated by arm lr5e4_kl10_t007 scoring 7.83 and 6.01 on byte-identical configs at the same seed, a gap larger than most differences this project has reported on the separation ratio.
