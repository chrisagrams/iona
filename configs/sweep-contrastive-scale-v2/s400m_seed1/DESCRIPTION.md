Contrastive has only ever been run at 50m; denoise gains with scale, so this asks whether the embedding does too. Six seeds per scale because the separation ratio has sd 0.75 at a fixed seed (job 8844111) and a single run per scale would resolve nothing -- with six, the standard error of a scale-to-scale difference is 0.43. lr is 2e-5 rather than the nominal grid winner 5e-4: means are indistinguishable at this noise level, so the choice falls to worst case, and 5e-4 collapsed to the floor in one of its four arms while 2e-5 never did. split_seed is pinned so every arm is scored on identical held-out data.
